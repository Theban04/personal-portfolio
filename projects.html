My Projects

Boutique E-commerce Website — Client Project

I contributed to a multi-page shopping website for a real boutique client. It includes a shop, cart, checkout flow, contact links, and an admin-only area where the client can update product information and upload product photos. I used agentic AI tools during development and manually troubleshot problems they could not resolve. The website is hosted through GoDaddy and cPanel.

I built a locally accessible app to organize my personal investment records. It calculates profit and helps me review the information over time, so I can make more informed decisions about my future plans.

Web Database Integration Project

I created a locally hosted university website to learn how websites connect with databases. I used HTML and CSS, with limited JavaScript, and XAMPP as the local environment. This project helped me understand database connections and troubleshoot setup problems.

University Mini-Games Collection

Across these projects, I used C, C++, Java, and HTML in some of the games. They helped me practise turning game rules into program logic and building interactive experiences.
